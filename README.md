# Персонализированные баннеры для Telegram-воронки

Инструмент превращает список подписчиков в серию персональных баннеров и рассылает их через Telegram-бота. Подходит онлайн-школам, курсам, коучам и ретритам, которым нужна рассылка с картинками без дизайнера.

## О проекте

Данные каждого человека (имя, должность, компания) подставляются в HTML-шаблон, а headless-браузер превращает страницу в картинку. Так в баннере получается настоящая типографика, градиенты и логотип, которых трудно добиться обычной отрисовкой изображений из кода.

Воронка из трех касаний: интерес, решение, дедлайн. На каждый этап заготовлено по три варианта макета. Оформление задается профилем бренда в YAML, сами шаблоны при этом не меняются.

## Задача

Рассылка с одной картинкой на всю базу читается как реклама и быстро теряет отклик. Делать персональные баннеры руками не получится: на каждого подписчика нужен отдельный макет, а на три этапа прогрева втрое больше. Работа дизайнера на каждое касание съедает всю выгоду от персонализации.

## Решение

1. **Список подписчиков в CSV.** Колонки `name`, `role`, `company`, `telegram_id` и `variant` (какой вариант макета показать).
2. **Девять шаблонов.** По три варианта на этап. Интерес цепляет эмоцией, решение показывает предложение, дедлайн подталкивает к действию через ограниченное число мест или персональное обращение по имени.
3. **Профили бренда.** Шесть готовых стилей (wellness, corporate, creative, luxury, tech, minimal) плюс шаблон для своего. В профиле лежат логотип, цвета, шрифты, размеры, стиль кнопок и тон сообщений.
4. **Рендер в картинку.** html2image через Chromium сохраняет каждый баннер в PNG 1200×900.
5. **Рассылка.** Бот на aiogram отправляет каждому подписчику три баннера с кнопкой перехода на сайт. Если кто-то заблокировал бота, рассылка идет дальше. В конце выводится статистика: кому отправлено и какие варианты показаны.
6. **A/B-тест.** Вариант макета берется из таблицы или выбирается случайно (`--variant random`), чтобы сравнить, какой работает лучше.

## Результат

- Каждый подписчик получает баннер со своим именем, должностью и компанией.
- Серия из 15 макетов (5 подписчиков на 3 этапа) собирается примерно за полторы минуты, дизайнер не нужен.
- Шесть готовых профилей бренда, от сдержанного минимализма до премиального стиля.
- Девять шаблонов закрывают три этапа воронки, по три варианта на каждый.

## Стек технологий

| Технология | Зачем используется |
|---|---|
| **Python** | Язык проекта, в контейнере 3.11 |
| **aiogram** | Рассылка баннеров в Telegram с кнопкой перехода |
| **Jinja2** | Подстановка данных подписчика в HTML-шаблон |
| **html2image + Chromium** | Превращает HTML-страницу в PNG с полноценной версткой |
| **pandas** | Чтение таблицы подписчиков |
| **PyYAML** | Профили бренда: цвета, шрифты, логотип, размеры |
| **Pillow** | Обработка готовых изображений |
| **python-dotenv** | Токен бота в `.env`, вне кода |
| **Docker** | Запуск с уже установленным Chromium |

## Структура репозитория

- `bot_funnel.py`: точка запуска, генерация и рассылка.
- `config.py`: загрузка профилей бренда.
- `utils.py`: рендер шаблонов в картинки.
- `templates/`: девять HTML-шаблонов и общие стили.
- `profiles/`: профили бренда, `custom_sample.yaml` служит образцом для своего.
- `assets/`: логотипы, иконки и фоновые паттерны. Как их подключить, описано в `assets/README.md`.
- `users.csv`: пример списка подписчиков.
- `test_basic.py`: проверка структуры проекта.

## Запуск

Нужен Python 3 и Chromium (`brew install chromium` на macOS, `apt-get install chromium-browser` на Ubuntu).

```bash
pip install -r requirements.txt
cp env.example .env       # BOT_TOKEN от @BotFather и BASE_URL для кнопок
```

Заполните `users.csv` своими подписчиками. Telegram ID человека можно узнать через бота `@userinfobot`. Чтобы бот смог написать человеку, тот должен хотя бы раз нажать у бота «Start».

```bash
python3 bot_funnel.py --list-profiles              # список профилей
python3 bot_funnel.py --test --brand wellness      # только картинки в output/, без отправки
python3 bot_funnel.py --send --brand wellness      # рассылка
python3 bot_funnel.py --send --variant random      # случайные варианты для A/B-теста
```

Свой стиль: скопируйте `profiles/custom_sample.yaml` в `profiles/custom.yaml`, поменяйте цвета, шрифты и логотип и запускайте с `--brand custom`.

В Docker тестовая генерация запускается так: `docker compose run --rm funnel`. Готовые картинки появятся в `output/`.
